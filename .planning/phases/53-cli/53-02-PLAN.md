<objective>
为 `stats` 子命令暴露 CLI 时间段参数并实现优先级合并（CLI > config > 默认）：
1. `src/cli/opts.rs::Commands::Stats` 新增 `--from: Option<String>`、`--to: Option<String>`，将 `--top` 由必填默认 20 改为 `Option<u32>`（仍保留 `range(1..)` 校验）。
2. `src/cli/stats/mod.rs::handle_stats` 签名扩展为接收 `top: Option<u32>` / `from: Option<String>` / `to: Option<String>` 并执行 D-05 优先级合并。
3. `src/main.rs` 的 `Commands::Stats` 分发分支解构新字段并传给 `handle_stats`。

Purpose: 让用户通过 CLI 控制时间段，CLI 缺省时回落到 config 值，二者均缺省时不做时间过滤（沿用 v1.13 行为）。STATS-07（CLI 参数）+ STATS-09（优先级语义）在本 Plan 落地。本 Plan **不**修改 init 模板、**不**接入 validate 命令、**不**在 run_stats 入口做防御性时间格式验证（这些移到 Plan 03）。
Output: 用户运行 `sqllog2db stats -c config.toml --from "2024-01-01" --to "2024-01-31"` 不报错退出，且通过日志可观察到合并后的有效 from/to/top 已正确传递给 run_stats。
</objective>
