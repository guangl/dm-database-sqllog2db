## v1.10 Requirements

### 核心验证

- [x] **VER-01**: CSV 导出端到端验证通过（含边界情况：空文件、大文件、特殊字符）
- [x] **VER-02**: SQLite 导出端到端验证通过（含 schema 正确性、数据完整性）
- [x] **VER-03**: Pipeline 过滤器（include/exclude/indicators/sql）验证通过
- [x] **VER-04**: 参数归一化验证通过（达梦 SQL 参数替换正确）
- [x] **VER-05**: 并行 CSV 处理验证通过（rayon 多线程输出正确拼接）
- [x] **VER-06**: `cargo build --release` + `cargo test` + `cargo clippy --all-targets -- -D warnings` + `cargo fmt --check` 全通过

### 错误处理

- [x] **ERR-01**: 错误类型细分（IO 错误 / 格式解析错误 / 配置错误 / 导出错误），每种错误包含路径和行号上下文
- [x] **ERR-02**: 非致命错误（解析失败、单条导出失败）记录到 error log 后继续处理，不终止整个导出
- [x] **ERR-03**: 错误信息包含三要素：发生了什么、在哪发生（文件:行号）、建议修复

### 管道输入

- [x] **PIPE-01**: 支持 stdin 作为输入源（`--input -` 或 `cat log | sqllog2db run`），通过 `/dev/stdin` 路径映射实现
- [x] **PIPE-02**: stdin 模式下自动跳过文件发现和 pre-scan，事务级过滤降级时明确警告用户

### CLI 体验

- [x] **UX-01**: 处理进度实时显示（每 1024 条更新一次，非终端自动退化为文本状态）
- [x] **UX-02**: 处理完成后输出统计摘要（总记录数、成功数、错误数、处理速率、总耗时）
- [x] **UX-03**: `--help` 输出包含 3-4 个达梦场景的实用示例（通过 clap `after_help`）
- [x] **UX-04**: 错误输出格式统一，非致命错误实时输出到 stderr（不含进度条干扰）
