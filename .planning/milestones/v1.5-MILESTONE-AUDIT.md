## Critical Gaps (Blockers)

### GAP-1: Dead Links in README Will Break Lychee CI

**Affects:** DOC-09, SUPP-05
**Files:** `README.md:202-204`, `.github/workflows/lychee.yml`

README.md lines 202-204 contain live Markdown hyperlinks to files that do not exist:

```markdown
- [Contributing Guide](./CONTRIBUTING.md) _(Coming v1.6)_
- [Security Policy](./SECURITY.md) _(Coming v1.6)_
- [Architecture Documentation](./docs/architecture.md) _(Coming v1.6)_
```

The `_(Coming v1.6)_` is plain text **after** the hyperlink — lychee follows the href regardless. No `.lycheeignore` or `lychee.toml` exist to suppress these. The lychee CI workflow is correctly structured but will exit non-zero on the first run touching README.md, making SUPP-05 functionally broken.

**Fix options (choose one):**

A. Convert to plain text (removes href target):
```markdown
- Contributing Guide _(Coming v1.6)_
- Security Policy _(Coming v1.6)_
- Architecture Documentation _(Coming v1.6)_
```

B. Add `.lycheeignore` at repo root:
```
./CONTRIBUTING.md
./SECURITY.md
./docs/architecture.md
```

C. Create empty stub files (satisfies the link but creates misleading content).

Option A is recommended — it matches DOC-09's intent ("removed or replaced with placeholder marker") and requires no additional files.
