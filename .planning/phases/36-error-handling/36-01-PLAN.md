# Plan: Error Type Hierarchy & Context

**Phase:** 36
**Requirements:** ERR-01, ERR-03
**Goal:** Add ErrorSeverity, is_fatal(), context methods, and ErrorStats — without breaking ~30 existing error constructors.

## Design Principle

Add context via **methods returning Option** (not mandatory struct fields). This avoids breaking all construction sites. Only `ParserError::InvalidPath` gains a new optional `line_number` field.
