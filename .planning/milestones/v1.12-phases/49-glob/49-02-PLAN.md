## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-49-03 | Tampering | SqllogParser::expand_single 单条 input 失败传播 | mitigate | 任意 input 展开失败立即 return Err（不静默跳过），避免部分数据丢失被掩盖 |
| T-49-04 | Denial of Service | log_files() 合并大量 inputs | accept | sort + dedup 为 O(n log n)，n 受用户输入条目数限制；正常使用场景文件数远低于 OOM 阈值 |
| T-49-05 | Information Disclosure | NoFilesFound { inputs } 在 stderr 回显用户路径 | accept | inputs 由用户提供，回显是预期反馈；与 PathNotFound 同等级别 |
</threat_model>
