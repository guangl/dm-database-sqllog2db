Output: 更新后的 Cross.toml，包含固定 SHA digest 和源信息注释
</objective>

  <name>Task 1: 获取 ghcr.io 镜像的当前 SHA256 digest</name>
  <files></files>
  <action>
    查询 ghcr.io/cross-rs/aarch64-unknown-linux-gnu:edge 对应的 SHA256 digest。
    
    使用以下方式之一（推荐顺序）：
    1. 安装 `crane` 并运行：`crane digest ghcr.io/cross-rs/aarch64-unknown-linux-gnu:edge` —— 输出为 `sha256:abc123...` 格式
    2. 若无 crane，使用 curl 查询 GitHub Container Registry API（需处理 HTTP 重定向）
    3. 若 Docker 守护进程可用，运行：`docker manifest inspect ghcr.io/cross-rs/aarch64-unknown-linux-gnu:edge | grep -i digest` 并提取 sha256 值
    
    记录：
    - 获得的完整 SHA256 值（不含 `sha256:` 前缀的 32 字节十六进制）
    - 获取时间戳（用于注释中的可追溯性）
    - 若有镜像标签/版本信息（如 release date），也一并记录
  </action>
  <verify>
    <automated>echo "输出应为 64 个十六进制字符的 SHA256 digest，如 abc123def456...（共 64 位）"</automated>
  </verify>
  <done>

  </done>
