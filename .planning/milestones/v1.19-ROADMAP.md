## Milestone Summary

**Key Decisions:**

- CSV watch 追加语义：每次触发向现有 CSV 文件追加（append=true, overwrite=false），非全量重写；非首次触发时跳过 CSV header 写入
- write_error_log OpenOptions 双分支：append_error_log=true 时追加，false（run 路径）时截断，两种模式单元测试覆盖防回归
- handle_watch Ctrl+C 路径：返回 `Err(Error::Interrupted)`，main.rs `match` 分支调用 `process::exit(130)` — 与 `run` 命令保持一致
- macOS FSEvents `#[ignore]` 测试：保留为已知平台限制（D-01），文档化说明原因，不使用 `#[cfg(not(...))]` 跳过（以免遮蔽实际测试意图）
- Phase 71 mod.rs 拆分：WatchLoopState 字段升级为 pub(super) 以允许兄弟模块直接访问；仅供集成测试使用的 pub use 加 #[allow(unused_imports)] 消除 bin target 下 unused 警告

**Issues Resolved:**

- watch Ctrl+C 退出码 0 vs run 130 不一致（v1.18 tech debt，Phase 1 修复）
- write_error_log 覆盖写导致 watch 长时间运行只保留最近一次错误（v1.18 tech debt，Phase 1 修复）
- CSV watch 导出不支持（v1.18 tech debt，Phase 1 实现）
- VALIDATION.md 草稿状态（Phases 67/68/69/70），Phase 3 补全为正式文件
- 行覆盖率 91.86%（v1.18 基线），Phase 2 提升至 92.06%

**Issues Deferred:**

- watch 多目录监听（WATCH-10）
- watch 远程推送（WATCH-11）
- JSON Lines / Parquet 输出格式（FMT-01/02）

**Technical Debt Incurred:**

- macOS FSEvents `#[ignore]` 测试保留而非跳过，CI 在 macOS 上跳过这两条测试（可接受）
