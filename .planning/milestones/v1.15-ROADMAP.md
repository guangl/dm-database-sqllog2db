## Milestone Summary

**Key Decisions:**

- D-01/D-02: GitHub Actions action 版本锁定 @v4，不使用不存在的 @v6/@v7
- D-04/D-05: release artifact 暂存 + needs:[release] 串行化，消除竞争条件
- D-07: 删除 publish job（CARGO_REGISTRY_TOKEN 未配置，导致 release 全局失败）
- D-08: Cross.toml 使用 edge tag（优于 3 年前的 latest 0.2.5）
- scanner 模块 pub(crate) 可见性，与现有 pub(crate) mod parser 保持一致
- handle_run 物理行数 override 接受（cargo fmt 展开导致，逻辑语句数 ~37 满足设计意图）

**Issues Resolved:**

- GitHub Actions workflow 因无效 action 版本（@v6/@v7）导致 CI 失败
- 4 个并行 release build job 竞争写入 release notes，最后写入者覆盖前者
- publish job 因 CARGO_REGISTRY_TOKEN 未配置导致每次 release 失败
- stats/mod.rs 和 processor.rs 中重复的 parser 创建逻辑（DRY 违反）

**Issues Deferred:**

- CICD-01/02 GitHub Actions 运行时验证（需人工推送 PR/tag 后确认）
- Cross.toml edge tag 固定为 SHA digest（可复现性）
- handle_run 物理行数彻底满足字面约束（可提取 build_field_config + dispatch_processing）

**Technical Debt Incurred:**

- Cross.toml 使用浮动 edge tag，构建不完全可复现（后续里程碑应固定 SHA digest）
