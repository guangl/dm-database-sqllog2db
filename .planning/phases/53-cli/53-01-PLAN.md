       - 不引入新依赖（无 chrono / time / regex）
       - 使用 `s.as_bytes()` 进行按位置检查；调用前可选 `s.is_ascii()` 防御（非 ASCII 字符串直接走长度分支也会失败，但显式 is_ascii 更清晰）
