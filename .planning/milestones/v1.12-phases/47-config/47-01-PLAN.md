<objective>
将 `sqllog2db validate -c <config>` 的用户输出从 `log::info!`（带时间戳的内部日志格式）迁移到结构化的用户可读格式：成功时单行 `Configuration valid.`，失败时 `[FAIL] <field>: <reason>` + 缩进 `  hint: <text>`。

Purpose: 让用户无需阅读时间戳/模块名等日志噪声即可直接看到 validate 的结果；与 Phase 46 确立的 `[TAG] message\n  hint: ...` 输出规范保持一致。

Output:
- `src/cli/validate.rs::handle_validate` 重写为 `println!` 输出，不再 `use log::info`，全部通过仅输出 `Configuration valid.`
- `src/main.rs` 的 `Validate` 子命令分支特殊处理 `cfg.validate()` 的 `Err`：渲染为 `[FAIL] <field>: <reason>\n  hint: <suggestion>` 写到 stderr，退出码 `EXIT_FATAL`
- `tests/integration.rs` 中现有 `handle_validate` 集成测试更新为不依赖日志副作用；新增 1 个 CLI 端到端测试断言 `Configuration valid.` 输出和 `[FAIL]` 前缀
</objective>

fn format_error_output(error: &Error) -> String {
    let severity = error.severity();
    let hint = error.suggestion();
    if hint.is_empty() {
        format!("[{severity}] {error}")
    } else {
        format!("[{severity}] {error}\n  hint: {hint}")
    }
}
