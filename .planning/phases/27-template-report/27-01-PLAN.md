## Trust Boundaries

| Boundary | Description |
|----------|-------------|

| TemplateReporter → Filesystem | 写入 *_templates.csv 到文件系统 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-01 | Tampering | derive_template_report_paths | mitigate | derive_report_paths 仅使用 `file_stem()` 和 `parent()` 组合路径，不信任用户路径作为参数拼接（路径来自配置而非用户输入）。PathBuf 操作天然防止路径遍历。 |
| T-27-02 | DoS | TemplateReporter::write_csv | accept | BufWriter 16MB 缓冲有限；stats 条数受模板数约束（通常 &lt; 1000），内存风险可忽略。 |
| T-27-03 | Spoofing | TemplatesReportConfig 反序列化 | mitigate | serde 反序列化保证类型安全；路径字段为 String，无默认不安全操作。 |
| T-27-SC | Tampering | cargo 依赖（新增 itoa 如未使用已有） | mitigate | itoa 已在依赖中；无新包引入。 |
</threat_model>
