### CI/CD
- 修复 `.github/workflows/` 下 `ci.yaml`、`bench.yml`、`lychee.yml`、`pages.yml` 中 `actions/checkout` 与 `actions/upload-artifact` action 版本统一为 `@v4`（Phase 55）

- 重构 `release.yaml`：拆出独立 `create-release` job 先于 4 个 matrix build job 运行，消除并行写入 release body 的竞争条件（Phase 55）

### Changed
- `cli/run` 模块拆分：`handle_run` 提取为 7 个私有辅助函数（`resolve_input_files`/`merge_trxid_prescan`/`make_progress_bar`/`run_csv_parallel`/`run_sqlite_parallel`/`run_sequential`/`print_run_summary`），所有函数体 ≤40 行（Phase 58）
- 新建 `src/scanner.rs` 公共扫描模块，`stats` 与 `cli/run/processor.rs` 共享文件扫描逻辑（Phase 56）

### Added
- `tests/integration.rs` 新增 4 个 e2e 测试：run 子命令 CSV 输出验证、run 子命令 SQLite sqllog_records 表行数验证、init 子命令成功路径、init 子命令文件已存在退出非零（Phase 57）
- `stats` 命令 from ≤ to 跨字段校验（`validate_stats_time_range`）+ 4 个单元测试 + 1 个 e2e 测试覆盖 TEST-03（Phase 57）

### Fixed
- 删除 `src/cli/stats/mod.rs` 中遗留的 "not yet active" `warn!` 占位符（Phase 56 CLEAN-01）
- benches 文档：`benches/BENCHMARKS.md` 追加 CI Artifact 使用说明章节，记录命名规则、下载方式、JSON 结构、手动对比方法（Phase 56）

### Added
- `stats` 命令时间范围过滤：`--from` / `--to` CLI 参数 + `[stats]` 节 `from` / `to` 配置字段，支持 `YYYY-MM-DD` 与 `YYYY-MM-DD HH:MM:SS` 两种格式（Phase 53 STATS-07/08/09/11）

- `tests/integration.rs` 新增 7 个 stats CLI e2e 测试覆盖 STATS-07–11 + 2 个 --from/--to 过滤效果测试（Phase 53/54）

### Changed
- `opts.rs` Stats 变体的 `--top` 参数改为 `Option<u32>`，与 config 的优先级合并语义匹配（CLI > config，Phase 53 D-05）
