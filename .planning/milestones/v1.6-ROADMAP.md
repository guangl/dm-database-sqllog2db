# Milestone v1.6: 文档中文化 & 延后需求补全

**Status:** ✅ SHIPPED 2026-05-19
**Phases:** 24-27
**Total Plans:** 7

## Overview

将所有公开文档全面中文化，补全 v1.5 延后的文档和功能需求，去除文档中的 SVG 引用。模板统计结果支持独立 CSV 和 SQLite 报告文件输出。

## Phases

### Phase 24: 文档中文化 & 去 SVG 化

**Goal**: 用户能阅读全中文的 README、快速入门指南和配置参考文档，且文档中不再包含 SVG 截图和图表引用
**Depends on**: Phase 23 (v1.5)
**Plans**: 3 plans

Plans:
- [x] 24-01: README.md 中文化 + 去 SVG + book.toml language="zh"
- [x] 24-02: GitHub Pages 落地页中文化 + 移除 SVG Gallery
- [x] 24-03: docs/quickstart.md + docs/config-reference.md 中文化

### Phase 25: 延后文档补全

**Goal**: 用户能访问 CONTRIBUTING.md、SECURITY.md 和 docs/architecture.md 三份中文文档
**Depends on**: Phase 24 (中文化文档风格定稿后新文档遵循相同模式)
**Plans**: 1 plan

Plans:
- [x] 25-01: 创建 CONTRIBUTING.md、SECURITY.md、docs/architecture.md 三份中文文档

### Phase 26: GitHub Pages 多页文档站

**Goal**: GitHub Pages 从单页落地页升级为 mdBook 多页文档站，用户可通过导航栏访问各文档页面
**Depends on**: Phase 24, Phase 25 (所有文档内容定稿后进行站点重构)
**Plans**: 1 plan

Plans:
- [x] 26-01: 重构 SUMMARY.md 为四章导航 + 创建章节页面 + 重写首页概览

### Phase 27: 模板报告独立输出

**Goal**: 用户在启用模板分析时，能通过独立文件获取模板统计摘要报告
**Depends on**: Phase 23 (独立于文档阶段，仅涉及 src/ 代码变更)
**Plans**: 2 plans

Plans:
- [x] 27-01: [template.report] 配置段 + 自动派生文件名 + TemplateReporter CSV 报告
- [x] 27-02: TemplateReporter SQLite 三表范式化报告

## Milestone Summary

**Key Decisions:**
- README 改为中文（I18N-01）: 目标用户为中文 DBA，无需双语维护
- I18N + DESVG 合并为 Phase 24: 修改相同文件集（README、docs/*、site/）
- TMPL-03 为独立 CSV 报告（非 JSON）: 与既有 `*_templates.csv` 输出模式一致
- TMPL-03b 为独立 SQLite 报告: 补充另一种结构化输出格式
- `[templates]` 重命名为 `[template.report]`: 语义更清晰，移除向后兼容

**Issues Resolved:**
- 所有公开文档全面中文化
- SVG 截图和图表引用从文档中移除
- 延后的 DOC-01/02/03 文档全部补全
- GitHub Pages 单页升级为多页 mdBook 文档站
- 模板报告独立输出（CSV + SQLite 三表范式化）

**Technical Debt Incurred:**
