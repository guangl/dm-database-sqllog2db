    **Troubleshooting section (per D-02):**
    Title: `## Troubleshooting`
    
    Cover these common issues:
    1. **Config validation fails** — Common causes: missing `[sqllog]` section, invalid path, wrong exporter key
       - Example: `Config validation failed: missing field 'path'`
       - Solution: Ensure `[sqllog]` section has `path = "sqllogs"`
    2. **No output file created** — Check config has correct `file` path and `overwrite = true`
    3. **Parse errors in log** — Expected behavior per design: errors are logged to the error file (configured via `[logging]` section), processing continues
       - Check the error log file to see which lines failed to parse
    4. **Slow performance** — Ensure using release build (`cargo build --release` not `cargo build`), single-threaded streaming is always constant-memory
       - Check system I/O: the bottleneck is usually disk read speed for the input log files
    5. **sqllog2db: command not found** — Rust's cargo bin directory (`~/.cargo/bin`) needs to be in PATH
       - Solution: `export PATH="$HOME/.cargo/bin:$PATH"` or restart shell
