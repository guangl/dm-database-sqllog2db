to:
```rust
match process_log_file(...) {

        total_records += records;

    Err(e) => {

            error_stats.record_fatal(e.to_string());

        // Non-fatal file error: log, record stats, continue to next file
        log::warn!("Skipping file {}: {e}", log_file.to_string_lossy());
        eprintln!("[WARN] {}: {e}", log_file.to_string_lossy());
        skipped_files += 1;
    }
}
```

   Keep parallel path change minimal: add ErrorStats creation after the parallel call, set error stats from the returned values. For parallel path, non-fatal errors are already handled (skipped files tracked).
