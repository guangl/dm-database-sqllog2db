# Milestone v1.4: 代码重构 & 质量深化

**Status:** ✅ SHIPPED 2026-05-18
**Phases:** 17–20
**Total Plans:** 12

## Overview

系统性重构配置模型与代码结构，补全测试覆盖，大幅提升项目可维护性。将扁平配置字段重组为嵌套子表（[filter.include]/[filter.exclude]、[template]、[charts]），拆分 5 个超大源文件为模块化目录结构，消除重复代码，收紧可见性，并补全 7 份 VERIFICATION.md + 端到端/边界/proptest 测试。

## Phases

### Phase 17: 过滤器配置嵌套化

**Goal**: 用户可用 [filter.include] / [filter.exclude] 嵌套子表配置过滤条件，旧版扁平格式仍可正确解析
**Depends on**: Phase 16
**Plans**: 2 plans

Plans:

- [x] 17-01: Filters struct 重构：新增 IncludeFilters / ExcludeFilters，手写 Deserialize 向后兼容旧扁平格式，重命名 CompiledMetaFilters::try_from_include_exclude，SqlFilters 字段改名加 alias
- [x] 17-02: 调用方适配 + init 模板更新：config.rs / cli/run.rs / cli/init.rs / tests/integration.rs 切换到新 API，init 命令产出新嵌套格式

**Details:**
- 手写 `FiltersFeature::Deserialize` via `RawFiltersFeature` 中间结构（非 flatten+alias，serde#2341 不可靠）
- `IncludeFilters` + `ExcludeFilters` 替代删除的 `MetaFilters`
- `SqlFilters` 字段：`include_patterns`→`includes`, `exclude_patterns`→`excludes`（带 alias 向后兼容）
- `CompiledMetaFilters::try_from_include_exclude` 替代 `try_from_meta`
- init 模板更新为中英文双语新嵌套格式
- TDD 双 gate（RED→GREEN）合规

### Phase 18: 模板 & 图表配置嵌套化

**Goal**: 用户可在 [template] / [charts] / [replace_parameters] / [filter] / [output] 顶层子表集中管理所有功能配置；旧 [pipeline.*] 命名空间在 validate() 阶段被显式拒绝，错误消息列出 5 条迁移映射
**Depends on**: Phase 17
**Plans**: 3 plans

Plans:

- [x] 18-01: Config struct 与 pipeline mod 顶层化：新增 TemplateConfig / OutputConfig；删除 PipelineConfig / TemplateAnalysisConfig；Config 顶层新增 5 个 Option 字段 + `pipeline_deprecated` 私有字段；validate() 加旧路径检测
- [x] 18-02: 调用方迁移 + Exporter trait 升级：cli/run.rs / main.rs / validate.rs / show_config.rs / stats.rs 切换到顶层字段；write_template_stats 签名改为 `(csv_path: Option<&str>, sqlite_table: Option<&str>)`
- [x] 18-03: init 模板与集成测试：CONFIG_TEMPLATE_ZH/EN 添加 # [charts] 注释段；tests/integration.rs 新增 4 条端到端测试

**Details:**
- 删除 `PipelineConfig`（field_mask/ordered_field_indices 移至 `OutputConfig`）
- `TemplateConfig { enable, output_csv_path, output_sqlite_table }`（enable 非 enabled，对齐命名规范）

- `# [charts]` 注释形式避免 ChartsConfig=None 时 validate 报错

## Milestone Summary
