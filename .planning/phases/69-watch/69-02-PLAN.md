## Trust Boundaries

| Boundary | Description |

| 文件系统 → notify watcher | notify 事件路径作为不可信输入（监听目录可能被恶意写入）|

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-69-02-T1 | Tampering | notify Event 路径越界（监听目录外文件触发）| mitigate | RecursiveMode::Recursive 仅覆盖 cfg.sqllog.inputs 衍生目录；event.paths 直接用于打开文件，不通过 shell；Rust Path 无 shell metachar 风险（per RESEARCH security 段）|
| T-69-02-T2 | Tampering | 符号链接 .log 触发处理 | accept | handle_run 仅读取并解析日志内容，不执行外部程序；既有 parser 已硬化（RESEARCH security 段确认）|
| T-69-02-D1 | DoS | 短时间内大量 .log 文件创建导致 handle_run 串行积压 | accept | watch loop 单线程同步触发；当前阶段不引入 debounce（D-07）；Phase 70 可视实际负载评估 |
