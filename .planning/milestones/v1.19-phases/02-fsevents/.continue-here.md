## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| cargo test multi-filter syntax | `cargo test -- filter1 filter2 filter3` is not valid; libtest only accepts ONE filter string after `--`. Use a common prefix (e.g. `-- test_watch_0`) to match multiple tests. This caused a plan checker blocker and required 3 revision cycles. | advisory | Always verify `<verify>` commands match cargo test's actual CLI contract before planning. |
| `#[ignore]` fallback in plan action | Original plan action for Group 4 included a `#[ignore]` fallback that would have left coverage insufficient. Removed in revision. | advisory | Never use `#[ignore]` as a fallback in PLAN.md `<action>` — it silently reduces coverage without gating. |
