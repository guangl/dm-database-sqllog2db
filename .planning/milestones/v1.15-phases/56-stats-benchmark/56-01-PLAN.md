## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 文件系统 → scanner | scanner 接受 PathBuf 列表读取磁盘日志文件，路径来自调用方（已由上层 SqllogParser 校验）；本任务不引入新的外部输入面 |
| scanner → 调用方闭包 | scanner 通过 FnMut(&Sqllog) 将解析后记录传给调用方；记录引用生命周期由 scanner 持有，闭包不可逃逸 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-56-01 | Information disclosure | scanner.rs parse error 日志 | mitigate | log::warn! 中包含文件路径与 parser 库返回的错误消息（不暴露内部 SQL 内容），与 src/cli/run/processor.rs:146 现有行为对齐 |
| T-56-02 | Denial of service | 解析非法/超大文件触发 parse_error 风暴 | accept | parse error 不终止流程是设计目标（CLEAN-01 / RESEARCH Pitfall 3），ErrorStats 计数可被上层观察并人工介入；本 Phase 不引入退出码影响（CONTEXT Deferred） |
| T-56-03 | Tampering | 模块可见性提升导致外部 crate 误用 | mitigate | scanner.rs 使用 `pub(crate)`（PATTERNS §"模块可见性模式"），与现有 `pub(crate) mod parser` 一致，不暴露公共 API |
| T-56-04 | Repudiation | parse error 静默丢失无法追溯 | mitigate | 双重可观测：ErrorStats.parse_errors 计数 + log::warn! 文本输出（对齐 run 命令现有模式） |
| T-56-SC | Tampering | npm/pip/cargo installs | accept | 本 Phase 不安装任何新包（RESEARCH §Package Legitimacy Audit 明确"本 Phase 不安装任何新包，跳过此节"），无供应链威胁面 |
