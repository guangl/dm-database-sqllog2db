    替换 `src/pipeline/template_reporter.rs` 中 `write_sqlite()` 的 `todo!()` stub 为完整三表范式化实现（D-03）。

    ### 函数签名
    ```
    pub(crate) fn write_sqlite(path: &Path, stats: &[TemplateStats]) -> Result<()>
    ```

    ### 实现步骤（严格按以下顺序）：

    1. **导入**：文件头部添加 `use rusqlite::Connection;` 和 `use crate::error::{Error, ExportError};`

    2. **打开连接**：`Connection::open(path)` → `.map_err(|e| Error::Export(ExportError::DatabaseFailed { reason: format!("open template db failed: {e}") }))`

    3. **设置 PRAGMA**：复用与 `src/exporter/sqlite/mod.rs` `initialize_pragmas()` 完全相同的配置：
    ```
    PRAGMA journal_mode = OFF;
    PRAGMA synchronous = OFF;
    PRAGMA cache_size = 1000000;
    PRAGMA temp_store = MEMORY;
    PRAGMA page_size = 65536;
    ```
    通过 `conn.execute_batch()` 执行，错误包装为 `Error::Export(ExportError::DatabaseFailed { reason: ... })`。

    4. **BEGIN 事务**：`conn.execute_batch("BEGIN;")`

    5. **DROP+CREATE 三表**（D-03 要求的三表范式化设计）：
    
    ```sql
    CREATE TABLE IF NOT EXISTS template_keys (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        template_key TEXT NOT NULL UNIQUE
    );

    CREATE TABLE IF NOT EXISTS template_stats (
        template_key_id INTEGER NOT NULL PRIMARY KEY REFERENCES template_keys(id),
        count INTEGER NOT NULL,
        avg_us INTEGER NOT NULL,
        min_us INTEGER NOT NULL,
        max_us INTEGER NOT NULL,
        first_seen TEXT NOT NULL,
        last_seen TEXT NOT NULL
    );

    CREATE TABLE IF NOT EXISTS latency_percentiles (
        template_key_id INTEGER NOT NULL REFERENCES template_keys(id),
        percentile_name TEXT NOT NULL,
        value_us INTEGER NOT NULL,
        PRIMARY KEY (template_key_id, percentile_name)
    );
    ```

    6. **清理旧数据**（每次 run 重新写入）：
    ```sql
    DELETE FROM latency_percentiles;
    DELETE FROM template_stats;
    DELETE FROM template_keys;
    ```

    7. **遍历 stats 写入数据**（严格按以下字段映射）：
    - `INSERT INTO template_keys (template_key) VALUES (?1)` 使用 `rusqlite::params![s.template_key]`
    - 获取 `let key_id = conn.last_insert_rowid();`
    - `INSERT INTO template_stats (template_key_id, count, avg_us, min_us, max_us, first_seen, last_seen) VALUES (?1, ?2, ?3, ?4, ?5, ?6, ?7)`：
      - template_key_id = key_id
      - count = `s.count as i64`
      - avg_us = `s.avg_us as i64`
      - min_us = `s.min_us as i64`
      - max_us = `s.max_us as i64`
      - first_seen = `s.first_seen`
      - last_seen = `s.last_seen`
    - 写入 3 条 `latency_percentiles` 行（每条一个百分位）：
      - `(key_id, "p50", s.p50_us as i64)`
      - `(key_id, "p95", s.p95_us as i64)`
      - `(key_id, "p99", s.p99_us as i64)`

    8. **COMMIT**：`conn.execute_batch("COMMIT;")`

    9. **错误处理**：所有 `rusqlite::Error` 使用 `.map_err(|e| Error::Export(ExportError::DatabaseFailed { reason: ... }))` 包装，保持与现有 `SqliteExporter` 一致的模式。

    10. **完成**：移除原有的 `todo!()` 行。

    ### 不做的操作：
    - 不需要 `prepare_cached`（写入量小，每轮 ~1000 行）
    - 不需要 batch_commit（单事务写完）
    - 不需要 `self` 状态（TemplateReporter 是无状态 struct）
    - 不需要处理 overwrite/append 模式（每次 run 自动覆盖）
  </action>
