## Milestone Summary

**Key Decisions:**

- README 采用纯英文最小骨架（D-02）——避免中英混排维护负担，国际可见性更高
- rsvg-convert 替代 ImageMagick——macOS ImageMagick 7 的 `convert` 命令字体渲染失败，librsvg 干净解决
- mdBook 单页落地页（非多页站点）——v1.5 范围约束，多页 mdBook 延后至 v1.6+
- ASCII art 替代 Mermaid.js（审计修复）——mdBook 默认不支持 Mermaid.js，渲染为原始文本；ASCII art 无依赖
- actions/checkout@v4（替代@v6）——v6 不是有效的已发布版本
- README 死链接转为纯文本——CONTRIBUTING.md/SECURITY.md/docs/architecture.md 推迟至 v1.6+，移除 href 防止 lychee CI 失败

**Issues Resolved:**

- README 395 行中英混排 → 208 行纯英文骨架
- CHANGELOG.md 空缺 → v1.0-v1.4 完整记录
- GitHub Pages 从无到有，自动部署流水线
- 文档死链接问题（lychee CI 门禁）

**Tech Debt:**

- Pages 落地页趋势折线图单数据点（points="369,89"）——渲染无可见趋势线（TD-2，非功能影响）
- Pages 落地页饼图含 3 个 0.0% 切片（TD-3，视觉噪音）
- site/src/index.md ~530 行内联 SVG（TD，可维护性，无功能影响）
- Nyquist VALIDATION.md 在所有 3 个阶段缺失（文档债务，非代码债务）
