## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Git push tag → GitHub Actions Runner | 维护者推送 v* tag 触发 release workflow |
| Runner → GitHub Marketplace Actions | runner 拉取 actions/checkout@v4、actions/upload-artifact@v4、actions/download-artifact@v4、softprops/action-gh-release@v2 |
| Runner → ghcr.io Docker 镜像 | aarch64-linux build job 通过 cross-rs 拉取 ghcr.io/cross-rs/aarch64-unknown-linux-gnu:edge |
| Runner → GitHub Artifact Store | build job 上传二进制，create-release job 下载 |
| Runner → GitHub Releases API | create-release job 调用 GitHub API 创建 Release |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-55-04 | Elevation of Privilege | release matrix build job 持有 contents: write | mitigate | 移除 build job 的 `permissions: contents: write`，仅 create-release job 声明（Pitfall 5），符合最小权限原则（ASVS V4） |
| T-55-05 | Tampering | release notes body 被并行 job 覆盖（原竞争条件） | mitigate | 重构为单一 create-release job 写入 release body，消除并发写入（D-04/D-05），CICD-03 直接对应 |
